# Polinusa

Aufbauspiel fürs Handy im Stil von Anno. Zeit: die Lapita-Phase der Austronesier, um 1500 v. Chr.
Ein Clan fährt los, findet leere Inseln, siedelt dort und treibt Handel über das offene Meer.

## Starten

`index.html` im Browser öffnen. Das Spiel ist eine einzige Datei ohne Build-Schritt.
Der Spielstand liegt im `localStorage` des Browsers.

## Was es schon gibt

- Eine durchgehende Seekarte mit stufenlosem Zoom und drei Detailstufen
- Nebel über unbekanntem Land, den Doppelkanus lichten
- Vier Inseln: Panua (hohe Insel), Motu (Atoll), Api (Vulkan), Namo (Atoll)
- Freies Bauen. Häuser sehen jedes Mal anders aus, Dächer werden mit der Zeit grau
- Handel über Schnüre zwischen den Inseln. Jede Fahrt knüpft einen Knoten, Wind ändert die Fahrzeit
- Kanuhaus baut das Doppelkanu für neue Inseln
