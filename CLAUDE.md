# Polinusa: Hinweise für die Arbeit am Spiel

- Die Oberfläche ist Deutsch. Antworten an den Nutzer in kurzen, einfachen deutschen Sätzen.
- Ideen und offene Punkte stehen in `IDEEN.md`. Vor neuer Arbeit dort nachsehen; Erledigtes dort streichen.
- Nach jeder Runde: `node tests/run.mjs` (mit `--long` für den langen Bot), README nachführen, `node tools/bundle.mjs`.
- Was spätere Zeit ist (Polynesien, Hawaiki), gehört erst nach die große Fahrt. Belegtes und Vermutetes im README trennen
  (Abschnitt „Was belegt ist und was später“).
- Die Hausansicht darf auf dem Handy nicht scrollen; der Handy-Test prüft das.
